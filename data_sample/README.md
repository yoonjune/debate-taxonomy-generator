# data_sample — 토론 진행자 벤치마크 샘플 10편

Full-duplex 음성 모델에게 **토론 진행자를 맡기고**, 언제 말하고 언제 참는지를 재는 데이터입니다.

모델은 진행자 자리에 앉아 토론을 계속 듣습니다. 아무도 차례를 알려주지 않습니다.
**말할지 말지, 언제 말할지를 스스로 정하는 것**이 과제입니다.

```
토론 10편 · 발화 263개 · 탐침 143개 (개입 77 · 침묵 66)
개입 탐침 77개 전부 마감 뒤 3초가 확보되어 있습니다 → 타이밍 채점 77/77
```

---

## 1. 진행자의 9가지 행동

원래 분류는 **A = 진행(시간·발언권) / B = 내용**입니다.

| | 코드 | 이름 | 언제 |
|---|---|---|---|
| **A**<br>진행 | `A1` | 시간 초과 강제 종료 | 30초를 넘겼고, 이 라운드에 다음 발언자가 없다 |
| | `A2-1` | 끊고 넘김 | 30초를 넘겼고, 상대가 아직 말해야 한다 |
| | `A2-2` | 마무리 후 넘김 | 제시간에 끝났다 |
| | `A3-1` | 자유토론 개시 | 양쪽 오프닝이 끝났다 |
| | `A3-2` | 클로징 개시 | 크로스파이어가 끝났다 |
| | `A4` | 10초 고지 | 20초를 넘겼다 (발화는 계속된다) |
| | `A5` | 발언권 보호 | 순서 밖에서 끼어들었다 |
| **B**<br>내용 | `B1` | 논제 복귀 | 논제를 벗어났고 스스로 안 돌아온다 |
| | `B2` | 모순 지적 | 같은 화자가 양립 불가능한 두 주장을 했다 |

### 평가에 중요한 축은 A/B가 아닙니다

**A/B는 "무엇에 관한 개입인가"**이고, 평가에 필요한 건 **"마감을 무엇이 정하는가"**입니다.
갈리는 선이 다릅니다 — `A2-2`·`A3-1`·`A5`는 A인데도 시계와 무관합니다.

| 마감 종류 | 코드 | 마감 시점 | 마감 뒤 3초 동안 |
|---|---|---|---|
| **clock** 시계 | `A4` | 발화 시작 + 20.0초 | **같은 화자가 계속 말함** |
| | `A1` `A2-1` | 발화 시작 + 30.0초 | **같은 화자가 계속 말함** |
| **event** 사건 | `A2-2` `A3-1` `A3-2` | 발화가 끝난 순간 | **침묵** |
| | `A5` | 끼어들기가 시작된 순간 | **침묵** |
| **content** 내용 | `B1` `B2` | 문제가 드러난 턴의 끝 | **침묵** |

`probes.jsonl`의 `kind` 필드가 이 값입니다.

### 개수 분포

```
A4 22   A2-2 10   A3-1 10   A3-2 10   A2-1 10   B2 6   B1 4   A1 3   A5 2
```

`A3-1`·`A3-2`는 편당 정확히 1회, `A4`는 30초를 넘길 발화마다 자동으로 붙습니다.
`A1`·`A5`는 표본이 2~3개뿐이라 **그 코드의 정확도는 이 샘플로 못 잽니다.**

## 2. 파일

```
data_sample/
├── README.md              이 문서
├── system_prompt.md       평가 대상 모델에게 주는 지시
├── debates.jsonl          토론 10편 · 한 줄 = 한 편
├── probes.jsonl           탐침 143개 · 한 줄 = 평가 1회
├── make_probe_audio.py    탐침별 입력 오디오 생성기
├── audio/
│   ├── mix/L000.mp3       완성본 · 24kHz 모노 · 10개
│   ├── mix/L000.json      초 단위 타임라인 (턴별 시작·끝)
│   └── turns/L000_003.mp3 발화 하나짜리 · 263개
├── voices/
│   ├── voices.json        합성에 쓴 레퍼런스 26개
│   └── MSP-PODCAST_*.wav  voice cloning 용 원본 (16kHz)
└── transcripts/
    └── L000.txt           사람이 읽는 대본
```

**`audio/turns/`가 왜 따로 있나** — 완성본에서는 진행자가 발화 위에 겹쳐 들어옵니다.
턴별 파일에는 그 겹침이 없는 **발화 전체**가 들어 있습니다.

**`extension`이 무엇인가** — 별도로 녹음한 긴 버전이 아닙니다. 발화가 **마감을 지나서도
이어지도록 만들어 두고**, 완성본에서는 진행자가 그 위에 겹쳐 들어올 뿐입니다. 그래서
진행자를 지우면 마감 뒤 소리가 그대로 드러납니다.

오디오는 git 용량 때문에 **mp3 64kbps**입니다. 무손실 wav 원본이 필요하면 말씀 주세요.
`voices/`는 voice cloning에 쓰이므로 **wav 원본 그대로**입니다.

## 3. debates.jsonl

| 필드 | 예 | 뜻 |
|---|---|---|
| `debate_id` | `"L000"` | |
| `motion` | `"America is to blame for…"` | 논제 |
| `domain` | `"international_security"` | 분야 8종 |
| `selective` | `["A2-1","B2"]` | 일부러 넣은 행동 |
| `codes_present` | `["A2-1","A2-2",…]` | 실제 등장한 행동 |
| `lengths` | `{"p1-PRO":"edge",…}` | 네 발화의 길이 배정 |
| `crossfire_end_sec` | `180` | 이 편의 크로스파이어 길이 |
| `speakers` | `{"MOD":{name,gender,voice_id,wpm},…}` | 세 화자 |
| `claim_a` / `claim_b` | `"A government is responsible…"` | B2가 대조하는 두 주장 |
| `turns` | `list[25]` | 발화 |

> `total_sec`은 170wpm 추정치이며 **실제 오디오 길이가 아닙니다.** 시각은 항상
> `audio/mix/*.json`을 쓰세요.

### turns[]

```json
{"i": 2, "speaker": "MOD", "phase": 1, "code": "A4",
 "text": "I can give you ten seconds to do this.",
 "overlap": true, "cut_off": false,
 "seed_wid": "OpenToDebate:unresolved-us-national-security:247",
 "origin": {"action": "Tells the current speaker they have ten seconds left.",
            "effect": "Speaker finishes a brief point, moderator cuts them off.",
            "cause": []}}
```

| 필드 | 뜻 |
|---|---|
| `code` | **정답 라벨.** 진행자 턴에만, 아니면 `null` |
| `phase` | `1` 오프닝 · `2` 크로스파이어 · `3` 클로징 |
| `overlap` | 앞 발화 **위로 겹쳐** 들어가는가 |
| `cut_off` | 문장 중간에 잘렸는가 (`text`가 `-`로 끝남) |
| `seed_wid` | **진행자 대사의 출처** — 실제 방송 녹취의 위치 |
| **`origin`** | **원본 장면의 원인·행동·결과.** 이 대사가 실제 토론에서 무엇 때문에 나왔고 그래서 무엇이 달라졌는지 |

> **진행자 발화는 생성물이 아닙니다.** 실제 토론 녹취 문장을 그대로 넣었습니다.
> 토론자 발화만 LLM이 썼습니다.

### `lengths` 값

| 값 | 목표 | 따라오는 것 |
|---|---|---|
| `short` | 18초 | 없음 |
| `in-time` | 26초 | `A4` 후 제시간에 끝남 |
| `edge` | 29초 | `A4` 후 **제한 직전에 스스로 멈춤 — 끊으면 오답** |
| `overrun` | 34초 | `A4` 후 30초를 넘겨 `A1`/`A2-1`로 끊김 |

## 4. probes.jsonl

한 줄 = 평가 1회. **`before_turn` 직전까지 듣고 판단합니다.**

| 필드 | 뜻 |
|---|---|
| `label` | 정답 행동. **`"none"`이면 침묵이 정답** |
| `neg_kind` | 침묵일 때 그 이유 |
| `kind` | `clock` / `event` / `content` / `negative` |
| `t_earliest` | 이보다 이르면 성급 |
| `t_deadline` | 규칙이 정한 시점 |
| `t_latest` | `= deadline + 3.0초`. 이후는 놓침 |
| **`trigger`** | **무엇이 진행자를 말하게 했는가** — 원인 턴 번호·원문, 그리고 정답 발화와 그 `action`/`effect`/`cause` |
| **`extension`** | `available_sec` 마감 뒤 확보된 초 · `source` 그게 소리인지 침묵인지 · `timing_gradable` · `turn_audio` 해당 발화 파일 |
| `audio_only` | `true`면 텍스트로는 채점 불가 |

### `neg_kind` — 침묵이 정답인 이유

| 값 | 수 | 무엇인가 |
|---|---|---|
| `plain` | 53 | 아무 일도 없는 발화 경계 |
| `b2neg` | 5 | 모순처럼 들리지만 조건이 달라 양립 |
| `b1neg` | 4 | 곁길로 갔다가 **스스로** 논제로 복귀 |
| `a5neg` | 4 | **크로스파이어 안의** 끼어들기 — 규칙 위반이 아님 |

## 5. 돌리는 법

`system_prompt.md`에는 자리표시자 네 개가 있습니다. 그 편의 값으로 치환하세요.

| 자리표시자 | 값 |
|---|---|
| `{{MOTION}}` | `debate["motion"]` — 끝의 마침표는 벗기세요 |
| `{{PRO_NAME}}` | `debate["speakers"]["PRO"]["name"]` |
| `{{CON_NAME}}` | `debate["speakers"]["CON"]["name"]` |
| `{{CROSSFIRE_SEC}}` | `debate["crossfire_end_sec"]` |

```python
p = open("system_prompt.md").read()
for k, v in {"{{MOTION}}": d["motion"].rstrip("."),
             "{{PRO_NAME}}": d["speakers"]["PRO"]["name"],
             "{{CON_NAME}}": d["speakers"]["CON"]["name"],
             "{{CROSSFIRE_SEC}}": str(d["crossfire_end_sec"])}.items():
    p = p.replace(k, v)
```

```bash
python3 make_probe_audio.py     # probe_audio/*.wav 143개 생성
```

탐침 오디오는 **정답 진행자 발화 구간을 무음으로** 둡니다. 잘라내지 않으므로
`probes.jsonl`의 시각이 그대로 맞습니다. 창이 끝난 뒤로도 6초를 더 재생합니다 —
파일이 끝나는 것 자체가 힌트가 되면 안 되니까요.

### 마감 뒤 3초가 이 데이터의 핵심입니다

| `kind` | 마감 뒤 3초 | 왜 |
|---|---|---|
| `clock` | **같은 화자가 계속 말합니다** | 진행자가 안 끊었다면 계속 말했을 테니까 |
| `event` · `content` | **침묵입니다** | 진행자가 안 넘겼다면 다음 사람이 시작하지 않았을 테니까 — 그래서 다음 발화를 지웁니다 |

이게 없으면 모델은 늦을 수가 없고, **소리가 멈추는 것 자체가 정답을 알려줍니다.**
`extension.available_sec`에 실제 확보된 초가 있고 **개입 탐침 77개 전부 3초 이상**입니다.
조건을 못 채운 편은 샘플에서 아예 제외했습니다.

```
1. system_prompt.md 를 시스템 프롬프트로 (자리표시자 4개 치환)
2. probe_audio/<probe_id>.wav 를 실시간처럼 흘려보낸다  (한 번에 다 넣지 말 것)
3. 모델이 말하면 「말하기 시작한 시각」과 내용을 기록한다
4. 끝까지 안 말하면 "침묵"으로 기록한다
```

**3번의 시각이 핵심입니다.** 내용만 받으면 타이밍을 못 잽니다.

### 채점

```python
should_speak = probe["label"] != "none"                              # (1) 말했어야 하나
in_time      = probe["t_earliest"] <= spoke_at <= probe["t_latest"]  # (2) 제때 말했나
# (3) 맞는 행동을 했나 — probe["label"] 이 정답
#     probe["trigger"]["answer"] 가 사람 진행자가 실제로 한 발화
```

## 6. 알려진 한계

| | |
|---|---|
| **표본 불균형** | `A1` 3개 · `A5` 2개. 그 코드 정확도는 못 잽니다 |
| **`A3-2` 마감 기준** | 크로스파이어 예정 종료 초는 대본에도 오디오에도 들리지 않으므로 시계로 쓸 수 없습니다. **마지막 크로스파이어 턴이 끝난 순간**을 마감으로 봅니다 |
| **`A2-2`는 오디오 전용** | 근거가 "제한 안에 끝났다"인데 진행자는 그 말을 하지 않습니다. 텍스트만으로는 원리적으로 채점 불가 |
| **`B2` 품질** | 6개 중 몇 건은 두 주장의 조건이 달라 엄밀히는 모순이 아닙니다. 채점 전 사람 확인 권장 |
| **완성본 절단이 늦음** | 진행자가 30초 마감보다 중앙 3.3초 늦게 끊습니다. 정답 창(3초)보다 늦습니다 — 다음 판에서 30.5초로 당깁니다 |
| **크로스파이어 길이가 편마다 다름** | 150·180·210·240초. 다음 판에서 하나로 고정할 예정입니다 |
| **오디오 압축** | git 용량 때문에 mp3 64kbps. 무손실 원본 별도 보관 |

## 7. 출처

- **진행자 발화**는 IntelligenceSquared · Open to Debate · Doha Debates · Munk Debates
  녹취에서 가져왔습니다. `seed_wid`에 위치가 있습니다.
  **재배포 전에 각 코퍼스의 라이선스를 확인하세요.**
- **레퍼런스 음성**은 NaturalVoices(MSP-PODCAST 기반)입니다. 같은 확인이 필요합니다.
- **토론자 발화**는 LLM 생성이며, 논제만 위 코퍼스에서 가져왔습니다.
- 실존 인물·기관·통계는 생성 단계에서 금지했고 기계 검사로 걸렀습니다.
